# human-in-the-loop-agent

Agente que detecta incertidumbre, pausa para input humano,
reanuda con contexto validado y deja un audit trail completo.

**Qué demuestra:** colaboración segura humano–agente con trazabilidad.

## Checklist de features clave

- [ ] Detección de incertidumbre / baja confianza
- [ ] Pausa del flujo hasta recibir input humano
- [ ] Reanudación con contexto validado
- [ ] Audit trail completo de decisiones y aprobaciones
